# 原文核验与文献卡

## 核验路径

先确认原文的标题、作者、版本、发表信息及来源文件，再阅读摘要、问题定义、方法、数据与实验、讨论及结论。需要整理整篇时覆盖全文；只核验特定论点时检查相关章节及会改变判断的上下文，明确实际阅读范围。

提取文本用于检索。涉及多栏版面、公式、表格、图注或提取缺失时查看原页面，不根据乱码猜测。记录物理 PDF 页码与文内页码的区别，优先同时给章节、表号或图号，方便再次定位。

## 每篇文献的最小记录

| 项目 | 应记录的内容 |
| --- | --- |
| 题录与版本 | 标题、作者、年份、发表载体、可验证标识及实际阅读版本；缺失项标明未确认。 |
| 摘要 | 用自己的话概括原摘要，标明为转述；如需逐字引用则保留引号与来源。 |
| 整篇主要研究 | 研究问题、对象、任务和适用范围。 |
| 主要数据源 | 数据来源、规模、筛选、划分、标注、许可及公开情况；原文未报告则如实标注。 |
| 主要内容 | 方法流程、输入输出、关键假设、系统或实验设置。 |
| 研究结果 | 观测值、指标、基线、平均方式、条件及负面结果。 |
| 研究结论 | 作者如何解释结果、结论适用范围与明确限制，和结果数值分开。 |
| 引用定位 | 对应原文页、章节、表或图；本地来源使用当前文档可解析的相对链接。 |
| 与课题关系 | 可直接支持的论点、仅能借鉴的设计、尚需自行验证的迁移假设，明确这是整理者分析。 |
| 核验状态 | 已核验范围、题录缺口、原文冲突、OCR 或页面无法确认之处。 |

整理表格不替代阅读原文。用于正式论文时，每条重要判断与其来源对应；内部文献编号只用于导航，正式编号按学校要求编排。

## 数字与结论边界

- 同时保留会改变含义的研究对象、数据规模、模型设置、指标和条件。区分 Precision、Accuracy、Recall、F1、F2、BLEU、主观评分及其评价对象，不把文本质量换算为审查正确率。
- 区分宏平均、微平均与汇总统计，说明分母。绝对比例之差写百分点，相对变化说明基准。重新计算需标明“根据原文数据计算”与计算方式。
- 摘要与正文、表格发生冲突时记录双方位置和数值，不静默修正或选择有利版本。无法消除冲突则限制该数字的引用。
- 检测、定位、修复、需求生成、追踪和形式化验证是不同任务。代码审查等领域的效果不能直接外推为中文需求审查效果。
- 区分证据位置存在与证据支持判断、追踪关系与冲突、未检索到与原文缺失、人工采纳与真值。按具体任务的标注规则判断。
- 学位论文与相关期刊论文共享数据或核心结果时，不累计为独立复现。仅从综述读到的研究标注转引范围，不声称已核对原始研究。

## 写入论文前

引用紧跟所支持的判断。方法与结果优先回到原始研究，综述适合支持分类或趋势；原文中出现某句话不等于它支持当前句子的全部含义。需要直接引用时准确标出引用范围，转述时重新组织语言并保留限定条件。

没有读到的材料、没有报告的实验和缺失题录均保持为缺口。可以完成措辞或结构调整，但在交付说明中列出仍待核验的事实，不把风格润色报告为事实核验通过。
